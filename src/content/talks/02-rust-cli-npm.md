Rust is taking over the JS tooling ecosystem, with many tools (such as TurboRepo, SWC, OXC / oxlint) being (re-)written in Rust for superior performance and reliability. But how do these projects do it? This talk will walk you through creating and publishing a Rust tool to NPM, from the basic CLI setup to the key challenges of CI/CD and supplying different binaries for different platforms. The main takeaway is to try this at home!
